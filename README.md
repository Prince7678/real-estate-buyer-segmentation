# Machine Learning Based Buyer Segmentation and Investment Profiling for Real Estate Market Intelligence

A Streamlit analytics dashboard that combines client attributes with sold-property activity and uses K-Means clustering to explore buyer segments. Hierarchical clustering is used as a validation comparison on a reproducible sample.

## Features
- Data cleaning and joining client profiles with sold property records
- Buyer segmentation using K-Means (default k=4)
- Hierarchical clustering comparison and sampled silhouette scores
- Buyer, investment-purpose, loan, satisfaction, purchase-value and geographic views
- Filters for country, region, acquisition purpose and client type
- Download filtered records as CSV

## Run locally
1. Install Python 3.10 or newer.
2. In this folder run `pip install -r requirements.txt`.
3. Run `streamlit run app.py`.

The source datasets are in `data/clients.csv` and `data/properties.csv`.

## Methodology notes
- `date_of_birth` is parsed into an approximate age as of 12 October 2026.
- Currency symbols and commas are removed from `sale_price` before numeric analysis.
- Sold property records are aggregated by `client_ref` and left-joined to client records.
- Missing property metrics for clients without a matched sold record are set to zero for the dashboard.
- Numeric features are median-imputed and standardized; categorical features are most-frequent-imputed and one-hot encoded.
- K-Means uses a fixed random seed for reproducibility. Hierarchical clustering and silhouette scores are calculated on a reproducible subset to control runtime.
- Cluster IDs are algorithmic labels, not inherently ordered buyer types. Interpret profiles from observed data rather than assuming C1/C2/C3/C4 correspond to the PRD's suggested labels.

## Project deliverables
- `app.py`: Streamlit dashboard
- `analysis.py`: reusable data loading and clustering workflow
- `clustered_clients.csv`: generated by running `python analysis.py`
- Research report: prepare after reviewing actual cluster outputs and metrics; do not report uncomputed findings.
